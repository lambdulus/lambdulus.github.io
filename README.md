# Lambdulus Website (production)

[![Production deploy](https://github.com/lambdulus/lambdulus.github.io/actions/workflows/handle-deploy.yml/badge.svg)](https://github.com/lambdulus/lambdulus.github.io/actions/workflows/handle-deploy.yml)

Production site for [Lambdulus](https://github.com/lambdulus/frontend), the web
notebook for playing with lambda calculus (teaching at FIT CTU).

- Live at https://lambdulus.github.io/
- Deployed from the `master` branch of `lambdulus/frontend`.

This repo is written by automation (`handle-deploy.yml` rebuilds everything on
every deploy). Do not edit the built files by hand.
